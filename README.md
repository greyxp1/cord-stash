# Cord stash

My custom Vencord/Equicord plugins and Discord theme.

## Plugins

- **AutoReact:** Automatically reacts to messages with configurable emojis based on the author or channel.
- **ClientPreferences:** Applies configured notification and voice preferences at startup and login. Unconfigured preferences remain unchanged. Applied values stay saved when the plugin is disabled.
- **DiscordPopoutTitle:** Marks Discord popout titles so window manager rules can distinguish them from ordinary browser windows.
- **FakeDeafen:** Makes you appear muted and deafened while still allowing you to hear voice chat.
- **LocalEdit:** Locally edits other users' messages and saves the changes between sessions; edits are visible only to you.

## Theme

- **Catppuccin Mocha:** Applies the Catppuccin Mocha palette to Discord, replaces emojis with Apple's set, and hides the window controls.
